# Onova Push notifications Server

To enable debug mode (print requests and responses to and from GCM), set:

    DEBUG=node-gcm node app.js

## Getting Started

Install yarn:

```sh
npm install -g yarn
```

Install dependencies:

```sh
yarn
```

Set environment vars:

```sh
cp .env.example .env
```

Start server:

```sh
# Start server
yarn dev:start
```
